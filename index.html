Finnish Personal Identity Code (PIC)

Format: DDMMYYCZZZQ. DDMMYY = date of birth, C = century sign, ZZZ = individual number (odd = male, even = female), Q = check character. Rules: dvv.fi/en/personal-identity-code

1. Check a personal identity code

11 characters, for example 131052-308T


2. Calculate the check character

DDMMYY + century sign + individual number, for example 131052-308


3. Create a new personal identity code

Format DD/MM/YYYY, for example 13/10/1952. Years 1800–2099 are allowed.
